# Xrm Tools Hello World

This project is a demonstration of building Power Platform plugins and custom APIs using Xrm Tools extension for Visual Studio. You can watch the walkthrough of how I am building this in the YouTube playlist [Using Xrm Tools in Visual Studio](https://www.youtube.com/playlist?list=PLejZuRVoZE_InjLPQhjE2PV0f7z3Oa2RZ)

# What is Xrm Tools?

Xrm Tools is extension I wished I had starting Power Platform development. It makes Power Platform development native in Visua Studio by bringing you features like code completion, syntax highlighting, one-click deployment and more. Learn more about it from the [Xrm Tools Wiki](https://github.com/rezanid/xrmtools/wiki). You can get the extension right from Extensions tab in Visual Studio or from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=rezanid.XrmTools).

Consider giving it a 5-star in the VS Marketplace and star the repo, if you liked it. This will help other developers like you find it too.
